# HisCopy

菜单栏剪贴板历史工具（macOS）。**v0.3.0** 起支持全局快捷键呼出/隐藏历史面板（默认 ⇧⌘V），并具备剪贴板捕获、本地历史、GitHub Releases 应用内更新，以及更接近系统备忘录 / 聚焦搜索风格的原生界面。

## 功能

- **全局快捷键**：默认 **⇧⌘V**（Shift+Command+V）呼出/隐藏历史面板；可在设置中修改，写入 UserDefaults 并立即生效。基于系统 Carbon `RegisterEventHotKey` / `UnregisterEventHotKey`（零第三方依赖）。若快捷键被占用，菜单与设置会显示中文冲突提示。
- **剪切板捕获**：轮询 `NSPasteboard.changeCount`（约 350ms），采集纯文本、HTML/RTF、图片（TIFF/PNG）、文件 URL
- **忽略**：自身回写、以及 `org.nspasteboard.ConcealedType` / Transient / AutoGenerated（若存在）
- **历史**：最多 200 条 FIFO，Application Support JSON + 图片文件；搜索、点选写回剪贴板、删除/清空、暂停捕获（菜单栏可切换）
- **界面**：毛玻璃历史面板、系统字体与强调色选中行、SF Symbol、标准设置分组
- **在线更新**：检查 GitHub Releases，下载 `HisCopy.zip`，进程退出后旁路替换 `.app`（对齐 iReader，避免原地拆正在跑的二进制）

## 权限说明

- **全局热键**：仅用于打开/隐藏面板，使用 Carbon 热键 API，**通常不需要**辅助功能（Accessibility）权限。
- **不**做 Accessibility 模拟粘贴：点选历史只会把内容写回系统剪贴板，需你自行 ⌘V。若将来实现「一键粘贴到当前应用」，那时才需要辅助功能权限。

## 限制

- 构建为 **ad-hoc 签名、未公证**
- 开机自启开关目前为占位（尚未接 `SMAppService`）

## 下载

从 [Releases](https://github.com/BianYanhui/HisCopy/releases) 或 [Actions](https://github.com/BianYanhui/HisCopy/actions) 下载 `HisCopy.zip`。

### 未公证打开方式

- 右键 App →「打开」
- 或终端：`xattr -cr /path/to/HisCopy.app`

## 本地开发

用 Xcode 打开 `HisCopy.xcodeproj`，选择 scheme **HisCopy** 运行。

要求：macOS 13.0+，Xcode 16+。零第三方依赖。

## 发版

合并到 `main` 后打 tag 触发 CI 构建并创建 Release：

```bash
git tag v0.3.0
git push origin v0.3.0
```
